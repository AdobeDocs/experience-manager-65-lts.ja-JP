# 受け入れとサインオフ{#acceptance-and-sign-off}

前述したように、[受け入れテスト ](/help/sites-developing/planning.md)は、次の検証に使用されるテストの特別なカテゴリです。

* このプロジェクトは顧客の要件を満たしています。
* 顧客がプロジェクトを承認する。

顧客とプロジェクトマネージャーは、要件を定義する必要があります。 最終請求に関連することが多いため、それぞれに特に重要です。

そのため、次の要件を満たす必要があります。

* 可能な限り早く定義します。
* 必要に応じて更新します。
* パートナーと顧客の両方が、変更を正式に承認して署名する必要があります。
