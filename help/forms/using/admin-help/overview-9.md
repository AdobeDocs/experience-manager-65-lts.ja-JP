# Forms Workflow の概要 {#overview-of-forms-workflow}

Forms Workflow では、ユーザーは人間中心のプロセスを設計、管理および最適化することができます。 Forms Workflow を使用すると、システムとユーザーをつなぐ、自動ビジネスプロセスアプリケーションを管理することもできます。
